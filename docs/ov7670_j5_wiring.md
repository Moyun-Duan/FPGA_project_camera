# OV7670 到 EGO1 J5 接线说明

本文档用于把 2x9 OV7670 模块接到 EGO1 V2.2 的 J5 扩展口。不要按排数直接插，必须按信号名逐根连接。

依据：

```text
EGO1 V2.2 硬件手册: https://e-elements.readthedocs.io/zh/ego1_v2.2/
当前工程约束: constraints/ego1_template.xdc
```

## 1. 结论

OV7670 模块常见是 2x9，共 18 针。EGO1 的 J5 是 2x18，共 36 针，其中：

```text
J5-35 / J5-36: 3.3 V
J5-33 / J5-34: GND
J5-1  到 J5-32: FPGA IO
```

本工程只使用 J5 的部分 IO。不能把 OV7670 的 2x9 排针直接整体插到 J5 的某半边，因为 J5 顶部包含电源和地，且信号顺序和 OV7670 模块不一致。

建议使用：

```text
杜邦线，母对母，一根一根接
```

## 2. 当前工程的接线表

按 OV7670 模块丝印信号名连接到 EGO1 J5。OV7670 不同模块的物理顺序可能不同，必须以你手上模块的丝印为准。

| OV7670 模块信号 | 连接到 EGO1 J5 | FPGA 管脚 | 方向 | 说明 |
|---|---|---|---:|---|
| `VCC` / `3V3` | `J5-35` 或 `J5-36` | 电源 | 电源 | 只接 3.3 V，不要接 5 V |
| `GND` | `J5-33` 或 `J5-34` | 地 | 地 | 必须和 FPGA 共地 |
| `PWDN` | `J5-1` | `B16` | FPGA -> 摄像头 | 当前工程输出低，使摄像头工作 |
| `VSYNC` / `VS` | `J5-2` | `B17` | 摄像头 -> FPGA | 帧同步 |
| `HREF` / `HS` | `J5-3` | `A15` | 摄像头 -> FPGA | 行有效 |
| `D0` | `J5-4` | `A16` | 摄像头 -> FPGA | 数据 bit0 |
| `D1` | `J5-5` | `A13` | 摄像头 -> FPGA | 数据 bit1 |
| `D2` | `J5-6` | `A14` | 摄像头 -> FPGA | 数据 bit2 |
| `D3` | `J5-7` | `B18` | 摄像头 -> FPGA | 数据 bit3 |
| `D4` | `J5-8` | `A18` | 摄像头 -> FPGA | 数据 bit4 |
| `D5` | `J5-9` | `F13` | 摄像头 -> FPGA | 数据 bit5 |
| `D6` | `J5-10` | `F14` | 摄像头 -> FPGA | 数据 bit6 |
| `D7` | `J5-11` | `B13` | 摄像头 -> FPGA | 数据 bit7 |
| `XCLK` / `MCLK` | `J5-12` | `B14` | FPGA -> 摄像头 | 当前工程固定约 25 MHz |
| `SIOC` / `SCL` | `J5-13` | `D14` | FPGA -> 摄像头 | SCCB/I2C 时钟 |
| `SIOD` / `SDA` | `J5-14` | `C14` | 双向 | SCCB/I2C 数据，通常需要上拉 |
| `RESET` / `RST` | `J5-15` | `B11` | FPGA -> 摄像头 | 当前工程随 `reset_n` 释放 |
| `PCLK` | `J5-19` | `D15` | 摄像头 -> FPGA | 像素时钟，当前约束使用 MRCC 管脚 |

当前工程未使用：

```text
J5-16, J5-17, J5-18, J5-20 到 J5-32
```

## 3. 不能直接按排插的原因

EGO1 J5 是 2x18：

```text
每一列 18 个位置
总共 36 个位置
```

OV7670 是 2x9：

```text
每一列 9 个位置
总共 18 个位置
```

两者数量差一半，而且 J5 顶部有 3.3 V 和 GND。直接插上去通常会出现以下风险：

```text
1. 摄像头 VCC 接到普通 IO
2. 摄像头 GND 接到 FPGA 输出
3. FPGA 输出和摄像头输出互相顶住
4. PCLK 没接到工程指定的 J5-19/D15
5. 数据线 D0-D7 全部错位
```

因此只能按信号名用杜邦线逐根连接。

## 4. 上电前检查清单

断电状态下：

```text
1. 找到 OV7670 模块丝印上的 VCC 和 GND。
2. 找到 EGO1 J5 的 3.3 V 和 GND。
3. 用万用表蜂鸣档确认所有 GND 是连通的。
4. 确认 OV7670 VCC 只接 J5-35 或 J5-36 的 3.3 V。
5. 确认 OV7670 GND 只接 J5-33 或 J5-34。
6. 确认 PCLK 接 J5-19，不是 J5-20。
7. 确认 D0-D7 没有反序。
8. 确认没有相邻杜邦线短路。
```

如果 OV7670 模块上看不到信号丝印，先不要上电。需要从卖家页面、模块原理图、模块正面丝印，或万用表连通性确认 18 个针脚定义。

## 5. 最小安全上电步骤

第一次不要急着看图像。按这个顺序做：

```text
1. 只接 VCC 和 GND，确认摄像头模块没有异常发热。
2. 断电。
3. 接 XCLK、RESET、PWDN。
4. 烧录完整工程，测 XCLK 是否约 25 MHz。
5. 断电。
6. 接 SIOC、SIOD。
7. 上电后观察 camera_config_done LED。
8. 断电。
9. 接 PCLK、VSYNC、HREF、D0-D7。
10. 上电后先用 mode_sw=00 看灰度图。
```

这种分步接法比一次性接满更容易定位问题，也能降低损坏风险。

## 6. 需要优先测的信号

用示波器或逻辑分析仪按顺序测：

| 顺序 | 信号 | 期望现象 |
|---:|---|---|
| 1 | `XCLK` | 约 25 MHz 连续时钟 |
| 2 | `RESET` | 释放后为高 |
| 3 | `PWDN` | 工作时为低 |
| 4 | `SIOC` | 初始化阶段有脉冲 |
| 5 | `SIOD` | 初始化阶段有数据变化 |
| 6 | `PCLK` | 摄像头开始输出后有时钟 |
| 7 | `VSYNC` | 周期性帧同步 |
| 8 | `HREF` | 行有效脉冲 |
| 9 | `D0-D7` | 随 PCLK 变化 |

如果 `XCLK` 没有，先不要查其它摄像头信号。如果 `XCLK` 有但 `PCLK` 没有，优先查摄像头供电、RESET、PWDN、SCCB 初始化和 PCLK 接线。
